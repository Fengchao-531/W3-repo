The function `get_hotels_address` is then called to get the address of the selected hotel. The function `create_calendar_event` is then called to add an event to the calendar on April 25th 2024 to remind the user to book the hotel.

The function `list_available_offers` is called to get a list of available offers that may help satisfy the user's secondary preferences. The function `apply_offer` is then called to apply one of the offers to the user's booking.

The function `get_hotels_address` is called to get the address of the hotel, which is then used as the location for the calendar event.
