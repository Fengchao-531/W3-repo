# Qwen Instruct

No standalone Qwen snapshot is currently installed on this machine. Set the
snapshot path before running:

```bash
export QWEN_MODEL_PATH=/absolute/path/to/qwen/instruct/snapshot
bash XLLMs/Qwen/run.sh exp1 --limit 1
bash XLLMs/Qwen/run.sh exp1
bash XLLMs/Qwen/run.sh exp3
```

Results, traces, and hidden states are stored in this directory.
