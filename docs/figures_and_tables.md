# Figures and Tables

RQ1 figure scripts use summary CSVs to visualize adoption under E and UC, matched source conditions, and beginning/middle/end placement for M and BM. In the position figure, benefit-matched benign distributions use gray hatched fills; markers are filled rather than hollow.

RQ2 figure scripts visualize layer-wise UC−E target-code support and component intervention effects from the current model-generated JSONL records. The plots include a relative late-depth marker at 0.875. Head and region analyses use the same matched checkpoints and preserved source labels.

RQ3 figure scripts show malicious execution rates by defense configuration under user-context placement. All figure source data derive from newly generated output folders. CSV tables are produced by `source-relocation analyze`.
